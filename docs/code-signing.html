Code signing policyПолитика за подписване на кода

How releases are built and signed, and who is allowed to approve them. Как се създават и подписват версиите и кой има право да ги одобрява.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: we have applied to the SignPath Foundation. Until the application is approved, releases are not signed yet, and Windows shows a “Windows protected your PC” warning when you install. Състояние: подадохме заявка към SignPath Foundation. Докато не бъде одобрена, версиите още не са подписани и Windows показва предупреждение „Windows защити вашия компютър“ при инсталиране.

What is signedКакво се подписва

  • The app itself (Assistant.exe, Assistant.Core.dll) and the installer (DesktopAssistant-win-Setup.exe). Самата програма (Assistant.exe, Assistant.Core.dll) и инсталаторът (DesktopAssistant-win-Setup.exe).
  • Only files built from the source code in this repository by its Release workflow on GitHub Actions. Nothing built on a personal computer is ever signed. Само файлове, създадени от изходния код в това хранилище от неговия процес Release в GitHub Actions. Нищо, създадено на личен компютър, не се подписва.
  • Every signing request is approved by hand before anything is signed. Всяка заявка за подписване се одобрява ръчно, преди нещо да бъде подписано.

Included open-source componentsВключени компоненти с отворен код

The installer also contains these components from other projects. They are not signed by us: Инсталаторът съдържа и тези компоненти от други проекти. Те не се подписват от нас:

  • .NET runtime and WPF (Microsoft, MIT license)среда и WPF (Microsoft, лиценз MIT)
  • Velopack installer and updater (MIT)инсталатор и обновяване (MIT)
  • NAudio microphone and sound (MIT)микрофон и звук (MIT)
  • Whisper.net andи whisper.cpp speech recognition (MIT)разпознаване на реч (MIT)
  • Everything SDK file search interface (voidtools)интерфейс за търсене на файлове (voidtools)

Downloaded later by the setup wizard, only when you choose them, and not part of the signed installer: Ollama and its AI model, the speech model, Piper and its voices, and Everything. Изтеглят се по-късно от съветника за настройка, само ако ги изберете, и не са част от подписания инсталатор: Ollama и неговият модел, моделът за реч, Piper и гласовете му, и Everything.

Changes proposed by anyone else (pull requests) are reviewed by a committer before they are merged. The members are the people with write access to the repository; their GitHub accounts use two-factor authentication. Промени, предложени от други хора (pull requests), се преглеждат от автор, преди да бъдат приети. Членовете са хората с право на запис в хранилището; профилите им в GitHub ползват двуфакторно удостоверяване.
